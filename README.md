# Stretches

A personal stretching-timer app (Expo / React Native). Pick a stretch and a time,
or build a routine — it counts down hands-free with voice + haptic cues.

- **Timer engine** — pure, tick-driven, multi-segment (`src/timer/`).
- **Library** — all `category: stretching` entries from the public-domain
  [exercises dataset](https://github.com/yuhonas/free-exercise-db), generated by
  `scripts/build-library.ts` (`src/stretches/`, photos in `assets/stretches/`).
- **Routines** — build, reorder, persist (AsyncStorage), play guided (`src/routines/`).

## Develop & iterate (free — no Apple account)

The fastest loop, and **free for as long as you like** — runs inside **Expo Go**:

```bash
bun install
bunx expo start        # press i, or scan the QR with Expo Go on your iPhone
```

Install **Expo Go** from the App Store first. Edits hot-reload instantly. The whole
app (voice, haptics, keep-awake, storage, SF Symbols) runs in Expo Go, so this needs
no Apple Developer account — ideal for testing for a few days before committing to a
standalone build.

```bash
bun test          # run the test suite (engine, hook, library, routines)
bunx tsc --noEmit # typecheck
```

### Regenerate the stretch library

```bash
bun run scripts/build-library.ts   # refreshes library.data.json + images.ts (re-uses cached photos)
```

## Install on your iPhone (standalone, via EAS)

This produces a real home-screen app via **internal/ad-hoc distribution** (~1-year
provisioning — no TestFlight 90-day expiry).

> **Requires the paid [Apple Developer Program](https://developer.apple.com/programs/) ($99/yr)** —
> ad-hoc distribution does not work with a free Apple ID. (For free iteration, use
> Expo Go above.) Also needs a free [Expo account](https://expo.dev).

### Initial setup (run once)

```bash
bunx eas-cli@latest login                 # log into Expo
bunx eas-cli@latest init                  # link project (writes projectId/owner to app.json — commit it)
bunx eas-cli@latest device:create         # register your iPhone — open the link/QR ON the phone
bunx eas-cli@latest build -p ios --profile preview
#   prompts: Apple login -> let EAS manage credentials -> select your registered device
```

When the cloud build finishes (~10–20 min), open the printed **QR/URL in Safari on
your iPhone** to install. First launch: trust the developer under
*Settings → General → VPN & Device Management*.

### Recurring updates

```bash
# Once, to enable over-the-air updates:
bunx eas-cli@latest update:configure

# JS-only changes (no rebuild) — installed app pulls it on next launch:
bunx eas-cli@latest update --channel preview -m "describe the change"

# Native changes (new modules) or yearly re-provision — rebuild:
bunx eas-cli@latest build -p ios --profile preview
```

## Build profiles (`eas.json`)

| Profile | Use |
|---|---|
| `development` | dev client build (internal) for on-device debugging |
| `preview` | **internal/ad-hoc standalone app** — what you install on your phone |
| `production` | store-ready build (not needed for personal use) |
